## 📝 Descripción

**BarberShop** es un sistema web completo diseñado para gestionar barberías y peluquerías de manera eficiente. Permite administrar servicios, barberos, citas y usuarios con una interfaz moderna, responsive y fácil de usar.

El proyecto está desarrollado siguiendo las mejores prácticas de programación:
- ✅ Arquitectura **MVC** (Modelo-Vista-Controlador)
- ✅ Programación **Orientada a Objetos (POO)**
- ✅ Patrón **Singleton** para la conexión a la base de datos
- ✅ **PDO** para consultas seguras contra inyección SQL
- ✅ URLs limpias con **mod_rewrite**

## ✨ Características

###  Página Principal
- Landing page moderna con diseño premium
- Sección hero con estadísticas
- Servicios destacados
- Sección "Sobre nosotros"
- Call-to-action para reservar citas

### 💇 Gestión de Servicios
- Listado de servicios con filtros y búsqueda en tiempo real
- Tarjetas modernas con animaciones
- Creación de nuevos servicios (solo admin)
- Precios y duración visibles

###  Sistema de Citas
- Agendamiento de citas con validación de disponibilidad
- Selección de servicio, barbero y horario
- Estados de cita: pendiente, confirmada, cancelada, completada
- Vista diferenciada para admin y cliente

### 👤 Panel de Administración
- Gestión completa de servicios
- Administración de citas
- Control de estados

### 🎨 Diseño
- 100% responsive (mobile-first)
- Tipografía premium (Playfair Display + Poppins)
- Iconos Font Awesome
- Animaciones suaves al hacer scroll
- Paleta de colores profesional
